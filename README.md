# Taguri 手繰

頭の中に散らばったものをたぐり寄せて束ねる、シンプルなマインドマップ。
ブラウザだけで動きます。サーバーもデータベースも不要です。

---

## GitHub Pages で公開する手順

ブラウザだけで完結します。Git のコマンドは使いません。

### 1. リポジトリを作る

1. <https://github.com/new> を開く
2. **Repository name** に `taguri` と入力
3. **Public** を選ぶ（無料プランで Pages を使うには Public が必要です）
4. 「Add a README file」などのチェックは **すべて外したまま**
5. **Create repository** を押す

### 2. ファイルをアップロードする

1. 作られたリポジトリの画面で **uploading an existing file** のリンクを押す
   （見当たらなければ **Add file** → **Upload files**）
2. このフォルダの中身を **すべて選択して**、そのままドラッグ＆ドロップする
   - フォルダごとではなく、**中のファイルを直接** 入れてください
   - `.nojekyll` は隠しファイル扱いになることがあります。見えない場合は
     エクスプローラーの「表示」→「隠しファイル」を有効にしてください
3. 下の **Commit changes** を押す

### 3. Pages を有効にする

1. リポジトリ上部の **Settings** → 左メニューの **Pages**
2. **Source** を `Deploy from a branch` にする
3. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
4. 1〜2分待ってページを再読み込みすると、上部に公開URLが出ます

```
https://<あなたのユーザー名>.github.io/taguri/
```

これをブックマークすれば完了です。

## アプリとしてインストールする（任意）

公開URLを Chrome か Edge で開くと、アドレスバーの右端に
インストールのアイコン（⊕ や 🖥 のような形）が出ます。

押して **インストール** を選ぶと、Taguri のアイコンでスタートメニューや
タスクバーに入り、独立したウィンドウで起動します。オフラインでも開けます。

- Chrome: メニュー → 「キャスト、保存、共有」→「ページをアプリとしてインストール」
- Edge: メニュー → 「アプリ」→「このサイトをアプリとしてインストール」

## 中身を更新するとき

`index.html` を書き換えて、GitHub 上で **Add file** → **Upload files** から
同じ名前で上げ直せば置き換わります（1分ほどで反映）。

キャッシュが効いて古い画面が出る場合は、`sw.js` の先頭にある

```js
const CACHE = "taguri-v3";
```

の数字を 1 つ上げて一緒に上げ直してください。

## シートを使い分ける

ヘッダーの下のタブが、そのままマインドマップの一覧です。

- **追加** — 右端の `+`（ヘッダーの「新規」も同じ動きです）
- **切り替え** — タブをクリック。表示位置と拡大率もシートごとに覚えています
- **名前の変更** — タブをダブルクリック。ヘッダー左の名前からも変えられます
- **削除** — タブの `×`（確認が出ます。元に戻せません）

「元に戻す / やり直す」はシートごとに独立しています。別のシートでの作業が混ざることはありません。

---

## JSON で持ち出す・読み込む

**画像** ボタンのパネルで **JSON** タブに切り替えます。

- **書き出す** — 範囲を「このシート」か「すべて」から選んで保存します
- **読み込む** — 書き出した JSON を選ぶと、**既存のシートの後ろに追加**されます（上書きはしません）。画面に JSON ファイルをドラッグ＆ドロップしても読み込めます

別の PC やブラウザへ移すとき、バックアップを取るときはこれを使ってください。
同じ名前のシートがあると `(2)` が付いて区別されます。

---

## 画像として書き出す

ヘッダーの **画像** ボタンから、マップを PNG / JPEG で保存できます。

- **形式** — PNG は輪郭がくっきり出るので資料向き。JPEG はファイルが軽くなります
- **倍率** — 1× / 2× / 3×。印刷やスライドに貼るなら 2× 以上がおすすめです
- **背景を入れる** — 外すと背景が透過した PNG になります（JPEG は透過に非対応のため常に背景付き）
- **マップ名を入れる** — 画像の左上にマップ名を入れます
- **コピー** — クリップボードに直接コピーします（PNG のみ）

書き出されるのは表示中の範囲ではなく **マップ全体** です。折りたたんだ枝は件数のバッジとして描かれます。

---

## データの扱い

作ったマップは **開いているブラウザの中だけ** に保存されます（localStorage）。
GitHub にもどこのサーバーにも送信されません。

そのため次の点にご注意ください。

- リポジトリを Public にしても、公開されるのは**アプリ本体だけ**で、マップの中身は公開されません
- 別の PC やブラウザとは同期しません
- 保存先は URL ごとに分かれます。Pages 版に引っ越しても、以前の URL で作ったマップは引き継がれません
- ブラウザの「閲覧履歴データの削除」で Cookie とサイトデータを消すと、マップも消えます

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体。これ1枚で全機能が動きます |
| `manifest.webmanifest` | アプリ名やアイコンの定義（インストール用） |
| `sw.js` | オフライン起動用のサービスワーカー |
| `icon.svg` / `icon-*.png` | アイコン |
| `.nojekyll` | GitHub Pages の変換処理を止めるための空ファイル |

## キーボード操作

| キー | 動作 |
| --- | --- |
| `Tab` | 子トピックを追加 |
| `Enter` | 兄弟トピックを追加 |
| `F2` / ダブルクリック | 文字を編集 |
| `Delete` | トピックを削除 |
| `←` `↑` `→` `↓` | トピック間を移動 |
| `Space` + ドラッグ | 画面を移動 |
| `Ctrl` + ホイール | 拡大・縮小 |
| `Ctrl` + `Z` / `Ctrl` + `Shift` + `Z` | 元に戻す / やり直す |
| `Ctrl` + `0` | 全体を表示 |

ノードをドラッグすると枝を付け替えられます。相手の中央に落とすと子になり、
上端・下端に落とすとその位置に並びます。
